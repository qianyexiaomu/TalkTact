# 真机自检清单（发版前手动过一遍）

> 为什么要有这份：`ScreenRenderTest` 的截图只渲染**单个页面**，看不到「外壳 + 页面」的组合行为，
> 也测不到按键、系统对话框、文件选择器、以及真的和微信进程通信。下面这些项都是**截图测不出来**的，
> 而且历史上真的出过问题（见每项后面的「踩过」标注）。

用法：装包 → 照顺序点一遍 → 有一项不对就别发。

---

## 一、外壳与导航（最容易出事）

- [ ] **底部只有一条导航条。** 不能出现两层图标叠在一起。
      （踩过：新版页面嵌在旧 `App()` 里时，旧 `NavBar` 还画着，两条压在一起。）
- [ ] **顶部内容不贴状态栏、也不空一大截。** 标题与状态栏之间是一份内边距，不是两份。
      （踩过：`statusBarsPadding()` 在外层和页面里各加了一次。）
- [ ] **底部导航 3 格都能点，选中态是滑动的药丸**，切页有触觉反馈。
- [ ] **在二级页按系统返回 → 回上一级**；在首页按返回 → 退出 App。
      （踩过：没挂 `BackHandler` 时，任何二级页按返回都直接退出 App。）
- [ ] **进旧界面（首页右上角）→ 按返回 → 回新界面**。

## 二、首页数据（必须是真数据，不能是摆设）

- [ ] 「运行状态」卡：未注入时是白卡 + 灰点 + 「未启用」+ 一句怎么办；
      注入后变成**蓝底** + 「运行中」+ 具体原因（框架已注入 / service 通道已建立 / 微信进程里跑过）。
- [ ] 「模块 → 最近一次走的路」在你用微信之后会变成 `proxy` 或 `direct`，右边显示「x 分钟前」。
- [ ] 「微信 → 微信版本」显示真实版本号（不是「未安装」）。
      若显示未安装，检查 `AndroidManifest.xml` 里的 `<queries>` 是否还在。
- [ ] 「微信 → 最近心跳」在你用过微信后变成「x 分钟前」+ 绿色「正常」。
- [ ] 「信息」四格数字会随使用增长（调用次数 / tokens / 角色 / 候选会话）。

## 三、设置逐项（每项都要能改、能存、能返回）

> 每一项都验三件事：**能进去**、**改完立刻生效或能保存**、**返回后值还在**。

- [ ] 外观与背景：玻璃三档切换后立即变化；滑杆拖动 → 点「保存」→ 返回再进，值还在。
- [ ] 外观与背景 → 背景图：选一张图 → 首页/旧界面能看到；「恢复默认背景」能换回渐变。
- [ ] 接口自检：点「开始自检」→ 出现「通 · 往返 xxxms」；拔网/填错地址 → 出现失败原因。
- [ ] 接入与模型：服务商「更换」能展开、选中后收起；四个输入框改完点「保存」，返回再进值还在。
- [ ] 接入与模型 → 分级模式：打开后「第二套接口」留空 = 复用第一套；自检时两路延迟分别显示。
- [ ] 回复风格：点药丸能勾/取消；自定义风格加一个 → 上面多一个可勾选项；删掉 → 消失。
- [ ] 回复风格 → 按联系人：加一个人 → 进去勾几种 → 列表显示「N 种（单独）」；「清空」后变「跟随全局」。
- [ ] 自动分析：开关、参考条数、最短间隔、温度都能改，返回后值还在。
- [ ] 会话白名单：开关能切；手动加一个名字 → 列表里出现；移除 → 消失；候选区搜索能过滤。
- [ ] 图片与 OCR：开关 + 三档能切换；「最近一次识图」在用过一次微信识图后有内容。
- [ ] 本地代理：打开开关 → 状态栏出现前台服务通知；关掉 → 通知消失。
      改端口 →「保存端口」→ 提示「服务已重启」。
- [ ] 诊断：三份快照能「点一下复制」；「抓取微信界面」后稍等刷新，「界面诊断」有内容。
- [ ] 备份与迁移：导出 → 文件选择器能存成 json；导入这个文件 → 提示「已导入：配置 + N 个角色」。
- [ ] 关于：版本号与安装包一致。

## 四、注入侧（微信里）

- [ ] **在聊天列表里连续切换 3 个人（A→B→C→A）**，每进一个都等卡片出来再切。
      要点：**A 的卡片里不能出现 B 的对话内容**，B 的也不能。
      这是「消息错乱」的验收项——头两轮可能因为标题未确认而跳过（正常），第三轮必须正确。
      （踩过：切会话时标题先变、消息列表还在上一个会话，按「旧名字 + 新消息」分析会把 B 记到 A 头上。）
- [ ] **语音能读到转写**：在聊天页长按一条对方语音 → 「转文字」→ 等转写显示出来 →
      回到浮层点「重新识别」。候选应该基于语音内容，而不是只看到「[语音]」。
      如果没读到：先确认那条语音**确实显示了转写文字**（这一步读的就是屏幕上那段字，
      不会自己去调微信的转写接口）；轨迹里会写「[语音]」占位说明没找到转写。
- [ ] **往上翻聊天记录**（在聊天页里往上滑一屏再滑回来）：卡片**不该重新识别**、也不该被重置。
      判据：滑回底部后正文还是原来那份；轨迹里能看到「不在底部（还能往下滚）→ 正在往回翻历史」。
      翻到有新消息进来时，才会重新识别 —— 那才是应该发生的。
      （踩过：以前指纹里带了可见行数、屏身份算了整屏消息，滑一下就当成「这一屏变了」。）
- [ ] **快速来回切两个人**（A→B 立刻回 A）：卡片不应闪成别人的内容，最多停一轮不动。
- [ ] 打开任意聊天页，浮层卡片出现，配色是新界面的蓝（不是紫）。
- [ ] 卡片上的「↻ 重新识别」能刷新候选。
- [ ] 点候选能填进输入框（不会自动发送）。
- [ ] 白名单开启且名单为空时，**任何聊天都不出候选**（这是设计，不是 bug）。
- [ ] 改完任何设置后，**强行停止微信再打开**，新配置才生效（注入侧是微信启动时加载的）。

## 五、危险操作（防误触）

- [ ] 角色详情「删除这个角色」：第一次点只变成「再点一次确认删除」，第二次才真删。
- [ ] 恢复默认提示词：同样要点两次。
- [ ] 删除后返回，列表里确实没了；重进 App 也不会回来。

## 六、已知的正常现象（别当 bug 报）

- 未激活模块时首页是白卡（不是蓝卡）。
- 首页「微信版本」在未装微信的设备上显示「未安装」。
- 内置渐变背景上，玻璃导航条没有「折射」效果——页面是不透明的，底下没东西可模糊。
- 诊断/自检相关数据在没用过微信前都是「还没有」。
